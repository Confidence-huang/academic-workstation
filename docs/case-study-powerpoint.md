# Case study: synthetic presentation pilot

This case study describes the accepted shape of a pilot, not a universal host guarantee.

## Scenario

A structured figure is routed to an editable presentation capability. The pilot contains
three to six slides, a native chart or structured graphic, the visible markers SYNTHETIC
TEST DATA and NOT RESEARCH RESULTS, and no research observations.

## Evidence sequence

1. Record the route and the structured-source preservation decision.
2. Build the synthetic PPTX in a staging directory.
3. Inspect slide count, text markers, chart data, and shape classes.
4. Open, save, close, reopen, and repeat the structured checks in PowerPoint.
5. Export PDF through the primary full-argument call; if it fails, record the error and use
   the explicit compatible fallback.
6. Render every page, inspect the images, hash the final artifacts, and derive status.

The evidence must distinguish current-run native observations from historical source records.
An exported PDF alone does not prove PPTX editability.
