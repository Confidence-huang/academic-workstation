# Provenance note

The public repository contains original orchestration code, schemas, documentation, and
synthetic fixtures. The source project was inspected for routing decisions, historical
native-acceptance evidence, license records, and known fallback behavior. Private source
paths, credentials, original outputs, and machine-specific evidence remain outside this
repository.

Historical records are labeled HISTORICAL_SOURCE in private run evidence. Current tests and
the native pilot, when run, are labeled CURRENT_RUN. The distinction prevents a previous
successful machine state from being presented as a current universal guarantee.
